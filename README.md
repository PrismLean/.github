# PrismLean

**Lean software. Clear core.**

PrismLean is a small software studio building focused SaaS platforms and
cloud-native systems. We take products apart, keep what matters, and engineer
the rest properly.

[Website](https://prismlean.com) · [Docs](https://docs.prismlean.com) · [Blog](https://blog.prismlean.com) · [中文](./README.zh-CN.md)

## What we do

- **SaaS platform development** — end-to-end product engineering, from data
  model to billing to deployment.
- **Cloud-native architecture** — systems that scale without a dedicated ops
  team.
- **Technical consulting** — architecture reviews, cost reduction, and
  migration strategy for teams that need a second pair of eyes.

## How we work

We prefer boring, proven tools over shiny ones. Small surface area, clear
boundaries, and code that someone else can read in six months.

- **Modular by default** — one thing done well, composed with others.
- **Infrastructure as code** — reproducible, reviewable, reversible.
- **Security is not a feature** — least privilege, zero trust, no open
  inbound ports.
- **Documentation is part of the product.**
